# @odyssage/ui

## 役割
再利用可能なUIコンポーネントライブラリです。Storybookを使用したコンポーネント駆動開発を実践します。

## 責務
- **UIコンポーネント**: 再利用可能なReactコンポーネント
- **デザインシステム**: 一貫したUI/UXの提供
- **レイアウト**: 共通レイアウトコンポーネント
- **ページコンポーネント**: 複合的なページレベルコンポーネント

## 構成
```
src/
├── components/        # 基本UIコンポーネント
│   ├── Button/
│   ├── LoadingSpinner/
│   └── session/
├── layout/            # レイアウトコンポーネント
│   ├── Layout/
│   └── Navigation/
├── pages/             # ページレベルコンポーネント
│   ├── scenarios/
│   ├── session/
│   └── top/
└── styles/            # 共通スタイル
```

## 技術スタック
- **React**: UIライブラリ
- **TypeScript**: 型安全性
- **Tailwind CSS**: スタイリング
- **Storybook**: コンポーネント開発・文書化

## 設計原則
- **再利用性**: 複数の場所で使用可能なコンポーネント設計
- **分離**: ビジネスロジックとUIロジックの分離
- **一貫性**: デザインシステムに基づく統一感
- **アクセシビリティ**: 使いやすさを重視した設計

## 開発フロー
1. Storybookでコンポーネントを単体開発
2. 各コンポーネントにStoriesを作成
3. PropsとStateの設計を慎重に行う
4. フロントエンドアプリから利用

## 依存関係
- **使用される場所**: apps/frontend
- **スタイル**: Tailwind CSS preset使用

# @odyssage/lib

## 役割
プロジェクト全体で共有するユーティリティ関数とヘルパー関数を提供するパッケージです。

## 責務
- **日付操作**: 日付の処理・フォーマット用ユーティリティ
- **UUID生成**: 一意識別子の生成
- **共通関数**: 複数の場所で利用される汎用的な関数

## 構成
```
src/
├── dateUtils.ts       # 日付関連ユーティリティ
├── generateUUID.ts    # UUID生成
└── index.ts           # エクスポート定義
```

## 設計原則
- **純粋関数**: 副作用のない関数として設計
- **再利用性**: 複数のパッケージから利用可能
- **軽量**: 最小限の依存関係
- **テスタビリティ**: 単体テストしやすい設計

## 依存関係
- 外部ライブラリへの依存は最小限
- 他のパッケージに依存しない
- 全てのpackages・appsから利用される可能性

## 注意事項
- ビジネスロジックは含めない
- ドメイン固有の処理は@odyssage/domainに配置
- 汎用性を重視した実装

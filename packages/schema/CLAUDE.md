# @odyssage/schema

## 役割
APIの入力・出力データの検証スキーマを定義するパッケージです。Valibotを使用してHTTPリクエスト/レスポンスの型安全性を保証します。

## 責務
- **APIスキーマ**: リクエスト/レスポンスボディの検証スキーマ
- **バリデーション**: ユーザー入力データの検証ルール
- **型定義**: APIの型情報を提供

## 構成
```
src/
├── schema.ts          # メインスキーマ定義
├── nodes/             # GraphDBノード用スキーマ
└── relationships/     # GraphDB関係用スキーマ
```

## 技術スタック
- **Valibot**: 軽量なスキーマ検証ライブラリ
- **TypeScript**: 型安全性の提供

## 設計原則
- **型安全性**: 実行時とコンパイル時の両方で型を保証
- **再利用性**: 共通スキーマの定義と再利用
- **明確性**: わかりやすいバリデーションエラーメッセージ

## 依存関係
- **使用ライブラリ**: Valibot
- **使用される場所**: apps/backend（API検証）、apps/frontend（型情報）

## 注意事項
- ドメインエンティティとは異なる関心事（HTTP層の検証）
- ビジネスロジックは含めない
- APIの仕様変更に合わせてスキーマを更新

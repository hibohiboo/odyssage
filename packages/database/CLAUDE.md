# @odyssage/database

## 役割
データアクセス層を担当するパッケージです。ドメインモデルとデータベースの間の変換・永続化を担当します。

## 責務
- **スキーマ定義**: Drizzle ORMを使用したデータベーススキーマ
- **クエリ実装**: データの作成・取得・更新・削除操作
- **リポジトリ実装**: ドメイン層のリポジトリインターフェースの実装
- **マイグレーション**: データベーススキーマの変更管理

## 構成
```
src/
├── schema.ts          # Drizzleスキーマ定義
├── db.ts              # データベース接続設定
├── queries/           # クエリ実装
│   ├── insert.ts
│   ├── select.ts
│   ├── update.ts
│   └── stock.ts
├── migrations/        # マイグレーションファイル
└── test-utils/        # テスト用ユーティリティ
```

## 技術スタック
- **Drizzle ORM**: TypeScript-first ORM
- **PostgreSQL**: メインデータベース（Neon）
- **Testcontainers**: 統合テスト用のコンテナ管理

## 設計原則
- **型安全性**: Drizzleによる型安全なクエリ
- **分離**: ドメインロジックとデータアクセスロジックの分離
- **テスタビリティ**: 統合テストによる品質保証

## 依存関係
- **データベース**: PostgreSQL (Neon)
- **使用される場所**: apps/backend
- **ドメイン**: @odyssage/domain（今後追加予定）

## 開発フロー
1. スキーマ変更時はマイグレーションを生成
2. 統合テストでデータアクセスを検証
3. ドメインモデルとDBモデルの変換を適切に実装

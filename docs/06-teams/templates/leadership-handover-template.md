## 📝 **使用ガイドライン**

### **AI処理最適化テンプレート活用**

#### **構造化データ記録方式**
```markdown
必須項目(Required):
- 課題分類: [技術/協働/品質/スケジュール]
- 緊急度: [High/Medium/Low] + 期限
- 影響範囲: [個人/チーム/プロジェクト/組織]
- 対応状況: [完了/進行中/計画中/保留]

定量化項目:
- Before/After指標: 具体的数値・効率化率
- 工数・時間: 実測値・削減効果
- 品質指標: エラー数・完了率・満足度

実行項目:
- 次アクション: 具体的タスク・担当者・期限
- 確認方法: チェック基準・測定方法
- エスカレーション: 基準・連絡先・手順
```

#### **AI処理効率向上の要点**
```markdown
情報密度最適化:
- Priority 1-3による階層化・重要度明確化
- タスク指向: 実行可能な具体的指示
- 成功基準: 定量的・検証可能な完了条件

検索・参照効率:
- 構造化見出し: ## 問題分類 / ### 具体事象
- タグ・分類: #緊急 #技術課題 #協働改善
- 関連文書リンク: 参照先の明確な指定

継続性確保:
- 実行パターン: 成功手順・失敗回避策
- 監視項目: 定期確認・早期発見方法
- 改善サイクル: 学習・適用・評価・修正
```

---

**AI協働最適化サイクル**:

1. **実践記録**: 定量的成果・失敗パターン・解決手順の構造化記録
2. **パターン抽出**: AI処理可能な実践知識・判断基準の体系化  
3. **予防メカニズム**: 早期検知・自動化可能な回避策の開発
4. **効率化実装**: 成功パターンの標準化・再現可能な手順化

```markdown
- 成功体験重視・小さな積み重ねの文化醸成
```

### **段階的試行の5段階実行サイクル（必須遵守）**
```markdown
🔄 各タスクでの必須実行手順:
1. 📋 **計画段階**: 1つのタスクのみ特定・詳細計画策定
2. 🔍 **準備段階**: 環境確認・前提条件・リスク要因の事前確認
3. ⚡ **実行段階**: 1つのタスクのみ実行・他作業は完全停止
4. ✅ **確認段階**: 成功/失敗の明確判定・結果記録・学習抽出
5. 🔄 **次段階**: 成功時のみ次タスク検討・失敗時は問題解決優先

🎯 成功判定基準:
- TypeScriptエラー0・lint100%クリーン
- 動作確認完了・期待結果との整合
- 文書記録完了・学習内容の明文化
```

### **段階的実装の5段階実行サイクル**
```markdown
🔄 各実装タスクでの実行手順:
1. 📋 **計画段階**: 1つのコンポーネント・機能のみ特定・実装計画策定
2. 🔍 **準備段階**: 設計仕様確認・BDDテスト要件・技術要件の事前確認
3. ⚡ **実装段階**: 1つの対象のみ実装・他実装は完全停止
4. ✅ **確認段階**: 実装完了報告・ユーザーテスト依頼・TypeScript/lint品質確認
5. 🔄 **次段階**: ユーザーテスト結果Green時のみ次検討・Red/問題時は解決優先

🎯 成功判定基準:
- TypeScriptエラー0・lint100%クリーン
- ユーザーからのBDDテスト結果Green報告
- 人間協働でのUI動作確認完了
```

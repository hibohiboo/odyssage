### **Phase 3: 参加確認ダイアログ実装（統合完成）**

#### **3.1 確認ダイアログコンポーネント**
```markdown
📋 実装要件:
- モーダルダイアログ形式（背景オーバーレイ推奨）
- data-testid="confirmation-dialog" 属性追加（推奨）
- role="dialog" 属性でアクセシビリティ対応

表示内容:
- 確認メッセージ: 「このセッションに参加しますか？」
- セッション名の再表示
- 参加前の最終確認情報
```

#### **3.2 確認・キャンセルボタン実装**
```markdown
📋 ボタン実装要件:
1. 確認ボタン:
   - テキスト: 「参加する」または「確認」
   - data-testid="confirm-join-button"（推奨）
   - onClick: 実際の参加処理実行

2. キャンセルボタン:
   - テキスト: 「キャンセル」または「戻る」
   - data-testid="cancel-join-button"（推奨）
   - onClick: ダイアログを閉じる処理

配置: 一般的なダイアログボタン配置（確認:右、キャンセル:左）
```

#### **3.3 参加処理実装（基本版）**
```markdown
📋 参加処理要件:
- 確認ボタンクリック時の処理実装
- 現段階: セッション参加状態の更新（簡単な状態変更）
- 成功時: ダイアログ閉じる + 参加完了メッセージ表示
- 失敗時: エラーメッセージ表示 + ダイアログ保持

参加後の表示:
- 「セッションに参加しました」等の成功メッセージ
- 参加ボタンの状態変更（「参加済み」等に変更）
```

#### **完了判定基準**
```markdown
✅ Phase 3完了条件:
- 参加確認ダイアログが適切に表示される
- 確認・キャンセル両ボタンが機能する
- 参加処理が正常に実行される
- **全BDDシナリオがGreen状態になる**

テスト実行依頼: Phase 3完了報告時に「テスト実行してください」を依頼
```

### **推奨技術スタック・パターン**
```markdown
📚 既存コードベース準拠:

```

### **data-testid命名規則**
```markdown
📋 推奨data-testid:
// セッション詳細画面
- session-title: セッションタイトル
- session-description: セッション説明
- session-participants: 参加者情報
- join-session-button: 参加ボタン

// 参加確認ダイアログ
- confirmation-dialog: ダイアログ本体
- confirm-join-button: 確認ボタン
- cancel-join-button: キャンセルボタン
- join-success-message: 参加成功メッセージ
```

### **エラーハンドリング設計**
```markdown
🚨 基本エラー対応:
1. 404 Not Found: セッションが存在しない場合
2. ネットワークエラー: API通信失敗
3. 参加制限: 満員・終了済みセッション
4. 認証エラー: ログインが必要な場合

エラー表示:
- ユーザーフレンドリーなメッセージ
- 技術的詳細の非表示
- 適切な回復手段の提示
```

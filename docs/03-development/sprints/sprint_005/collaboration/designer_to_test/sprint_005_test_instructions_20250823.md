### **session-joining.feature 実装仕様**
```markdown
🎯 推奨BDD構造:
Feature: セッション参加 - Player文脈
  Player（プレイヤー）がセッションに参加するためのBDD
  プレイ体験開始前の重要なユーザージャーニー

Background:
  Given プレイヤーがアプリにアクセスしている
  And 参加可能なセッション "test-session-join" が利用可能である
  And セッション詳細情報が表示されている

Scenario: セッション参加の基本フロー（1つ目）
  Given プレイヤーがセッション詳細画面を表示している
  When プレイヤーが「このセッションに参加」ボタンをクリックする
  Then 参加確認ダイアログが表示される
  And 「参加する」「キャンセル」ボタンが表示される
  # 【目視確認必要】参加プロセスのUI・UX確認
  # 確認観点: ボタン配置・説明文・操作の分かりやすさ

Scenario: 参加確認・参加完了（2つ目・1つ目Green後に作成）
  # 1つ目完全成功後に段階的追加
```

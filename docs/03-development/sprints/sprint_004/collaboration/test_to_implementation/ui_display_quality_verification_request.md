## 🚨 **発見した表示品質問題**

### **問題概要**
BDDテスト実行時に、シーンタイトル・説明の表示で以下の品質問題を発見しました：

```html
<!-- BDDテストで取得された実際の画面表示 -->
終了セッション test-session-001⋯古い森の入り口古い森への入り口あなたは古い森の入り口に立っています。深い霧が漂い、木々の向こうから不思議な音が聞こえてきます。続ける
```

### **具体的問題点**

#### **1. テキスト表示の詰まり・区切り不備**
```html
問題: test-session-001⋯古い森の入り口古い森への入り口
期待: test-session-001 | 古い森の入り口
```

#### **2. 重複タイトル表示の可能性**
```html
問題: 古い森の入り口古い森への入り口  ← 2つのタイトルが連結？
期待: 古い森の入り口 (単一タイトル表示)
```

#### **3. 要素間の適切な区切り・スペーシング不足**
```html
問題: 入り口あなたは古い森の入り口に立っています
期待: 入り口\n\nあなたは古い森の入り口に立っています (改行・余白)
```

---

## 📋 **確認依頼事項**

### **Priority 1: 重複表示問題の調査**

#### **確認項目**
1. **シーンタイトル要素の重複確認**
   - `[data-testid="scene-title"]` 要素が複数存在していないか
   - 異なるコンポーネントから同じタイトルが表示されていないか
   - PlayHeader.tsx と SceneDisplay.tsx でタイトル表示が重複していないか

2. **データソース重複確認**
   - LocalStorageのシーンデータが重複登録されていないか
   - 同一シーンIDで複数のシーンデータが存在していないか
   - State管理でシーンデータが重複保持されていないか

#### **具体的確認手順**
```bash
1. http://localhost:5173/player/session/test-session-001/play にアクセス
2. DevToolsでDOM構造確認:
   - scene-title要素の数・内容確認
   - 重複するタイトル要素の有無確認
3. LocalStorage確認:
   - odyssage_session_test-session-001 の内容確認
   - odyssage_session_test-session-001_scenes の内容確認
```

### **Priority 2: レイアウト・スペーシング品質確認**

#### **確認項目**
1. **要素間の区切り・余白確認**
   - セッションタイトルとシーンタイトル間の適切な区切り
   - シーンタイトルとシーン説明間の適切な余白
   - 各UI要素の視認性・可読性

2. **CSS・スタイリング確認**
   - Tailwind CSSクラスの適用状況
   - margin, padding, 改行の適切性
   - レスポンシブ対応での表示崩れの有無

#### **具体的確認観点**
```css
期待するレイアウト:
┌─────────────────────────────────┐
│ [終了] test-session-001         │  ← PlayHeader
├─────────────────────────────────┤
│                                 │
│        古い森の入り口            │  ← SceneTitle (中央・目立つ)
│                                 │
│  あなたは古い森の入り口に立って  │  ← SceneDescription 
│  います。深い霧が漂い、木々の    │  (適切な改行・余白)
│  向こうから不思議な音が聞こえて  │
│  きます。                       │
│                                 │
│           [続ける]              │  ← ContinueButton
└─────────────────────────────────┘
```

### **Priority 3: データ整合性・品質確認**

#### **確認項目**
1. **シーンデータの一貫性確認**
   - title属性の正確性・一意性
   - description属性の完全性・表示適合性
   - backgroundImage属性の有効性

2. **コンポーネント間連携確認**
   - PlaySessionView → SceneDisplay → PlayHeader の適切な連携
   - Props受け渡しの正確性
   - State更新の適切性

## ⚠️ **重要な制約・注意事項**

### **BDD対応への配慮**
- **data-testid属性保持**: 現在使用中の4つの属性は削除しない
  - `session-title`, `scene-title`, `scene-background`, `continue-button`
- **テストデータ互換性**: 現在のLocalStorageデータ形式を維持
- **段階的修正**: BDDテスト実行に支障のない範囲での修正実施

### **MVP制約遵守**
- **必須機能の保持**: シーン表示・タイトル表示・説明表示機能の維持
- **パフォーマンス維持**: 表示速度・レスポンシブ性能の維持
- **技術制約遵守**: LocalStorage依存・クライアントサイド実装の維持

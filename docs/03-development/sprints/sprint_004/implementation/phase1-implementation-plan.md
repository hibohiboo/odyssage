## 🤝 協働プロセス

### 情報共有方法
1. **リアルタイム連携**: 設計判断・変更の即座共有
2. **日次同期**: 終日に進捗・課題・翌日計画の確認
3. **決定記録**: 重要判断の文書化・共有

### 責任分担（RACI Matrix）

| タスク | リーダー | 設計担当 |
|--------|----------|----------|
| プロジェクト方針・意思決定 | **A** (Accountable) | **C** (Consulted) |
| Player文脈アーキテクチャ設計 | **C** (Consulted) | **A** (Accountable) |
| UI/UX設計 | **I** (Informed) | **A** (Accountable) |
| 品質基準・技術制約確認 | **A** (Accountable) | **C** (Consulted) |
| 最終統合・承認 | **A** (Accountable) | **R** (Responsible) |

### エスカレーション・調整
- **技術的判断**: 設計担当が主導、リーダーが最終承認
- **プロジェクト方針**: リーダーが決定、設計担当が実装方法提案
- **優先度調整**: リーダーが判断、両者で実現方法検討

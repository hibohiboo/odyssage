# スプリント完了チェックリスト

## 📋 概要

スプリント完了時の必須更新項目・手順をまとめたチェックリスト。  
**目的**: 更新漏れ防止、ドキュメント同期の確保

## ✅ 必須完了手順

### Phase 1: 振り返りドキュメント作成

- [ ] **振り返りドキュメント作成**
  - ファイル: `sprint-XXX-retrospective.md`
  - 配置: `docs/03-development/sprints/sprint_XXX/`
  - 内容: 成果・課題・改善点・次スプリントへの引き継ぎ

- [ ] **期間・メタデータ確認**
  - SPRINT_CONFIG.mdと期間が一致していること
  - 参加者・関連ドキュメントリンクが正確であること

### Phase 2: 開発READMEの更新

- [ ] **現在スプリント → 完了スプリント移動**
  - ファイル: `docs/03-development/README.md`
  - セクション: "📊 現在のスプリント"
  - 対象スプリントを完了スプリント一覧に移動

- [ ] **完了スプリント順序確認**
  - 降順（最新 → 古い順）で並んでいること
  - リンク形式: `[[sprints/sprint_XXX/SPRINT_CONFIG|タイトル]]`

- [ ] **主要成果の簡潔記載**
  - 3つ以内の主要成果を箇条書き
  - ✅ マークで完了を明示

- [ ] **次期スプリント情報更新**
  - 次のスプリント番号・期間・テーマを記載

### Phase 3: スプリントREADMEの更新

- [ ] **現在状況セクション更新**
  - ファイル: `docs/03-development/sprints/README.md`
  - セクション: "### 現在の状況"

- [ ] **完了スプリント追加**
  - 降順で対象スプリントを先頭に追加
  - リンク形式: `[[sprint_XXX/SPRINT_CONFIG|タイトル]]`

- [ ] **次期スプリント情報更新**
  - sprint_XXX番号を次の番号に更新
  - 期間・テーマを更新

- [ ] **ディレクトリ構造説明の同期**
  - 必要に応じてディレクトリ構造の説明を更新

### Phase 4: 最終確認

- [ ] **リンク動作確認**
  - 各ドキュメント間のリンクが正常に動作
  - 特にFoamリンク `[[]]` の確認

- [ ] **情報一貫性確認**
  - すべてのファイルでスプリント番号・期間が一致
  - タイトル・テーマの表記が統一

- [ ] **次スプリント準備確認**
  - 次期スプリントの方向性が明記されている
  - 引き継ぎ事項が明確に記載されている

  - Foamリンク `[[]]` の動作確認

## ⚠️ よくある見落とし

### 更新忘れリスク

1. **スプリントREADME更新忘れ**
   - `docs/03-development/sprints/README.md`
   - 開発READMEのみ更新して忘れやすい

2. **期間情報の不一致**
   - SPRINT_CONFIG.mdと振り返りドキュメントの期間不一致
   - コピペ時の修正忘れ

3. **順序間違い**
   - 完了スプリントの昇順・降順混在
   - 一貫性のない並び順

### リンク切れリスク

1. **相対パス間違い**
   - ファイル移動時のパス更新忘れ
   - 階層構造の理解不足

2. **Foamリンク記法間違い**
   - `[[]]` 内のパス記述ミス
   - ファイル名変更時の更新忘れ

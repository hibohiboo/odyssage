# シーン追加機能 手動テストガイド

## テスト環境

### 前提条件
- フロントエンド: http://localhost:5173
- バックエンド: http://127.0.0.1:8787
- Neo4j GraphDB: 起動済み

### 必要なサービス起動
```bash
# フロントエンド
cd apps/frontend && npm run dev

# バックエンド  
cd apps/backend && bun run dev

# Neo4j (GraphDB)
bun run local:graphdb
```

## テスト手順

### 1. シナリオ作成（前提条件）
1. ブラウザで http://localhost:5173 にアクセス
2. 「シナリオ作成」ページに移動
3. 新しいシナリオを作成
   - タイトル: 「テスト用シナリオ」
   - 概要: 「シーン追加機能のテスト用」
4. 作成したシナリオの詳細ページに移動

### 2. シーン追加テスト
1. シナリオ詳細ページ下部の「シーン管理」セクションを確認
2. 「新しいシーンを追加」ボタンをクリック
3. シーン作成フォームが表示されることを確認
4. フォームに入力:
   - シーンタイトル: 「森の奥の小屋」
   - シーン概要: 「プレイヤーたちが森の奥で発見する古い小屋。重要な手がかりが隠されている。」
   - シーン順序: 1
5. 「シーンを保存」ボタンをクリック
6. 保存成功後、シーン一覧に新しいシーンが表示されることを確認

### 3. シーン編集テスト
1. 作成したシーンの「編集」ボタンをクリック
2. シーン編集フォームが表示されることを確認
3. シーン情報を変更:
   - シーンタイトル: 「森の奥の古い小屋」（タイトル変更）
   - シーン順序: 2（順序変更）
4. 「シーンを更新」ボタンをクリック
5. 更新成功後、変更内容が反映されることを確認

### 4. 複数シーン作成テスト
1. さらに2-3個のシーンを追加作成
2. シーン順序が正しく表示されることを確認
3. シーン一覧が順序通りに並んでいることを確認

### 5. エラーハンドリング確認
1. 必須フィールドを空にして保存を試行
2. 適切なバリデーションエラーが表示されることを確認
3. GraphDBサービス停止状態での動作確認（オプション）

### APIレスポンス確認
```bash
# シーン作成APIテスト
curl -X PUT http://127.0.0.1:8787/api/graph-scenes/test-scene-001 \
  -H "Content-Type: application/json" \
  -d '{
    "title": "テストシーン",
    "overview": "APIテスト用のシーン",
    "scenarioId": "test-scenario-001",
    "order": 1
  }'

# シーン一覧取得APIテスト  
curl http://127.0.0.1:8787/api/graph-scenes/scenario/test-scenario-001
```

```cypher
// シーンノード確認
```

## トラブルシューティング

### よくある問題

1. **シーンが表示されない**
   - ブラウザのリロードを実行
   - Network タブでAPI通信エラーを確認
   - バックエンドサーバーの起動状態を確認

2. **保存エラー**
   - フォーム入力内容を確認（必須フィールド）
   - GraphDBサービスの起動状態を確認
   - Console タブでJavaScriptエラーを確認

3. **GraphDB接続エラー**
   - Neo4jサービスの起動確認: `bun run local:graphdb`
   - 環境変数設定の確認（.dev.vars）

4. **認証エラー（将来的な問題）**
   - Firebase Authentication設定の確認
   - JWT トークンの有効性確認

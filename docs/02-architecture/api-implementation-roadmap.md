# API実装ロードマップ（案）

> 文脈ベースAPI設計で特定された不足機能の実装検討案

## ⚠️ **重要な注記**

**このドキュメントは実装検討案であり、承認済みの計画ではありません。**

- **現状**: 不足機能の特定・分類・検討段階
- **今後**: 優先順位・実装判断・リソース配分の検討が必要
- **決定事項**: やること・やらないこと・優先順位は未確定

## 📋 概要

### 背景
- **2025-08-10**: 文脈ベースAPI設計検討で重要な機能不足を特定
- **現状**: 既存API改修（パス見直し・ソース整理）のみ実施
- **将来**: 不足しているAPI機能の段階的実装が必要

### 実装方針
- **設計原則**: Hybrid Approach（参照・RESTful、更新・文脈特化）
- **優先度**: ビジネス価値・ユーザー体験への影響度で判定
- **段階的実装**: 既存システムへの影響を最小化

## 🎯 不足機能の分類

### **🔴 High Priority - ユーザー体験に直結**

#### **プレイヤー文脈のセッション機能**

**現状**: プレイヤー視点のセッション機能が完全欠如

**必要なAPI**:
```http
# プレイヤー参加可能なセッション一覧
GET /api/sessions?context=player
# レスポンス追加フィールド：
# - gmName: string           # GM名
# - canJoin: boolean         # 参加可能性
# - isParticipating: boolean # 参加状況
# - scenario: { difficulty, playerCountRange } # シナリオ詳細

# セッション参加申請
POST /api/player/{uid}/sessions/{id}/actions/join
# 機能：セッションへの参加申請・承認待ち状態管理

# セッション離脱
DELETE /api/player/{uid}/sessions/{id}/actions/leave
# 機能：セッションからの離脱・参加者数更新
```

**ビジネス価値**: 
- プレイヤーのセッション参加体験向上
- GMの参加者管理効率化
- TRPG コミュニティ活性化

**実装見積**: 中規模（2-3週間）
- 参加管理テーブル設計・実装
- 権限制御ロジック
- 通知機能（参加申請・承認）

#### **文脈別レスポンススキーマの実装**

**現状**: GM・Player で同一スキーマを使用、必要な情報不足

**必要な改善**:
```typescript
// GM文脈専用フィールド
interface GMSessionResponse extends BaseSession {
  canEdit: boolean;           // 編集権限
  canDelete: boolean;         // 削除権限
  editUrl: string;            // 編集画面URL
  manageUrl: string;          // 進行管理URL
  playerManagement: {         // 参加者管理情報
    pendingInvitations: number;
    activePlayersCount: number;
    playerList: Player[];
  };
}

// Player文脈専用フィールド
interface PlayerSessionResponse extends BaseSession {
  gmName: string;             // GM名
  canJoin: boolean;           // 参加可能性
  joinUrl: string;            // 参加申請URL
  viewUrl: string;            // 閲覧URL
  scenario: {                 // シナリオ詳細情報
    difficulty: string;
    playerCountRange: string;
    description: string;
  };
}
```

**ビジネス価値**:
- フロントエンド開発効率向上
- 型安全性確保
- UX改善（適切な情報表示）

**実装見積**: 小規模（1週間）

### **🟡 Medium Priority - 機能拡張・利便性**

#### **シナリオ作成者向け拡張機能**

**現状**: 基本的なCRUDのみ実装

**追加機能**:
```http
# シナリオ統計・分析
GET /api/authors/{uid}/scenarios/stats
# レスポンス：
# - stockCount: number       # ストック数
# - sessionCount: number     # 使用セッション数
# - averageRating: number    # 平均評価

# シナリオ利用状況
GET /api/authors/{uid}/scenarios/{id}/usage
# レスポンス：
# - sessions: Session[]      # このシナリオを使用したセッション一覧
# - feedback: Feedback[]     # フィードバック・レビュー
```

**ビジネス価値**:
- 作成者のモチベーション向上
- 品質改善のためのフィードバック循環
- プラットフォームの付加価値向上

**実装見積**: 中規模（2-3週間）

#### **権限・可視性制御の詳細化**

**現状**: 基本的な公開/非公開のみ

**追加機能**:
```http
# 詳細可視性設定
PATCH /api/authors/{uid}/scenarios/{id}/visibility
# 機能：
# - フレンド限定公開
# - 特定グループ限定
# - 期間限定公開

# アクセス権限管理
POST /api/authors/{uid}/scenarios/{id}/permissions
# 機能：
# - 特定ユーザーへの編集権限付与
# - コラボレーション機能
```

**ビジネス価値**:
- 柔軟な公開設定による利用促進
- コラボレーション機能による品質向上
- プライバシー配慮の向上

**実装見積**: 大規模（4-6週間）

### **🟢 Low Priority - 将来拡張・最適化**

#### **高度な検索・フィルタリング**

**現状**: 基本的な一覧取得のみ

**追加機能**:
```http
# 高度検索
GET /api/scenarios/search?q={query}&difficulty={level}&playerCount={range}&tags={tags}

# レコメンデーション
GET /api/gm/{uid}/scenarios/recommended
# 機能：過去のセッション履歴・好みに基づくレコメンド
```

#### **リアルタイム機能**

**現状**: 静的な情報のみ

**追加機能**:
```http
# WebSocket接続
WS /api/sessions/{id}/realtime
# 機能：
# - セッション状態のリアルタイム更新
# - 参加者の入退室通知
# - ライブチャット機能
```

#### **分析・監視機能**

**追加機能**:
```http
# システム全体統計
GET /api/analytics/platform
# 機能：
# - 活動統計
# - 人気シナリオランキング
# - 利用傾向分析
```

## 🔄 既存API改修との関係

### 並行作業
- **既存API改修**: パス見直し・ソース整理（現在実施中）
- **新機能実装**: 改修完了後に段階的実装

### 相互影響
- 新機能は改修後のAPI設計方針に準拠
- 既存改修で新機能の基盤（認証・権限制御）を強化

### 統合戦略
- 既存APIとの整合性確保
- 段階的リリース・A/Bテスト
- 後方互換性維持

## 💰 リソース・コスト見積

### 開発リソース
- **Phase 1**: 1名×3ヶ月（基本機能）
- **Phase 2**: 1-2名×3ヶ月（拡張機能）
- **Phase 3**: 1-2名×6ヶ月（高度機能）

### 技術負債・保守コスト
- **データベース拡張**: 参加者管理・統計テーブル
- **認証・権限制御**: 複雑化に伴う保守コスト
- **リアルタイム機能**: インフラ・運用コスト増加

### 収益・価値
- **ユーザー体験向上**: 参加率・継続率向上
- **プラットフォーム価値**: 差別化機能による競争力
- **データ活用**: 利用傾向分析による改善サイクル

## 🎯 成功指標・KPI

### Phase 1 KPI
- **参加率**: セッション参加申請・承認率
- **利用頻度**: プレイヤーのセッション閲覧・参加頻度
- **エラー率**: 新機能の障害・エラー発生率

### Phase 2 KPI  
- **作成者満足度**: 統計機能利用率・フィードバック
- **品質向上**: シナリオ評価・改善サイクル
- **コラボレーション**: 共同作成機能利用率

### Phase 3 KPI
- **検索効率**: 検索からセッション参加までのコンバージョン
- **リアルタイム体験**: ライブ機能の利用状況
- **プラットフォーム成長**: 総ユーザー数・アクティブ率

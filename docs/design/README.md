# Odyssage 設計ドキュメント

このディレクトリには、Odyssageプロジェクトの設計ドキュメントが格納されています。

## ディレクトリ構造

```
docs/design/
├── README.md                    # このファイル
├── database/                    # データベース設計
│   ├── hybrid-schema.md         # ハイブリッドDB構成の設計書
│   ├── scenario-creation-schema.md # シナリオ作成用スキーマ設計
│   └── (将来追加予定)
```

## 設計ドキュメントの管理方針

### 配置ルール
- **技術設計書**: `docs/design/` 配下に分野別に配置
- **実装コード**: `packages/` および `apps/` 配下に配置
- **API仕様書**: `docs/redocly/` 配下に配置（既存）

### 命名規則
- ファイル名: `kebab-case.md`
- ディレクトリ名: `kebab-case`
- 日本語でも英語でも可（プロジェクトの性質に応じて）

### 更新タイミング
- 設計変更時: 実装前に設計書を更新
- 実装完了時: 実装と設計書の整合性を確認
- レビュー時: 設計書も含めてレビュー対象とする
